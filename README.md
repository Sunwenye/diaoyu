# 铃声识别 + Arduino 串口触发（ring_detector）

实时监听音频输入，**每次听到目标铃声就通过串口向 Arduino 发送字符 `'1'`**（不烧录，只发信号）。

## 一、发送逻辑（对应你的需求）

| 情形 | 动作 |
|---|---|
| 识别到铃声 | **立即**发 `'1'`；并在 **random(1~5) 秒**后再补发一次 `'1'` |
| 超过 **15 秒**没有听到匹配声音 | 补发一次 `'1'`（静默心跳） |

板子收到 `'1'` 即执行一次「转 180°→保持 0.5s→回 90°」（约 1.7s）。

## 二、技术选型

| 环节 | 方案 | 选型理由 |
|---|---|---|
| 采集 | `sounddevice`（WASAPI） | pip 直装、延迟低；默认麦克风采集“外放”声音，`--loopback` 可内录 |
| 特征 | log-Mel 谱去趋势（detrend） | 去频响倾斜、保留精细峰结构，抗噪且能区分相近音高的提示音 |
| 匹配 | 帧能量加权（峰值下 14dB）+ 子序列 DTW + 余弦距离 | 低能量/噪声帧降权，允许铃声出现在任意位置 |
| 判定 | 能量门控 + 阈值（默认 0.22） | 命中即触发（`--confirm` 可调到 2~3 抗误报） |
| 输出 | `pyserial` 向 Arduino 发 `'1'` | 只发信号，不烧录板子 |

## 三、安装

```
python -m pip install -r requirements.txt
```
（依赖：sounddevice / numpy / scipy / soundfile / pyserial）

## 四、用法

```
run.bat --port COM5        # 指定串口（本机 Arduino 在 COM5）
run.bat                    # 自动检测 USB 串口
run.bat --no-serial        # 不发串口，仅打印（无板子时测试）
run.bat --verbose          # 打印每一步匹配距离
run.bat --list             # 查看音频设备
run.bat --selftest         # 离线自测
```
按 `Ctrl+C` 停止。

> 注意：若串口打不开（`Permission denied`），多半是 **Arduino IDE 的串口监视器**占用，关掉即可。

## 五、关键参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `--port` | 自动检测 | Arduino 串口，如 `COM5` |
| `--baud` | `9600` | 波特率（与板子 `Serial.begin` 一致） |
| `--no-serial` | 关 | 只打印不发送（测试用） |
| `--threshold` | `0.22` | DTW 距离阈值，越小越严格 |
| `--energy-gate` | `0.02` | 窗口 RMS 门控 |
| `--confirm` | `1` | 命中确认次数；调到 2~3 更抗误报 |
| `--window` / `--step` | `5.0` / `0.25` | 匹配窗口 / 判定步长（秒） |
| `IDLE_SEND_SEC` | `15.0` | 静默补发间隔（秒） |
| `SECOND_MIN, SECOND_MAX` | `1.0, 5.0` | 命中后补发第二次的随机间隔（秒） |
| `ENERGY_FLOOR_DB` | `14.0` | 帧能量加权激进度 |
| `DETREND_W` | `5` | mel 轴去趋势窗 |

## 六、实机实测（本机 Windows + Realtek 麦克风 + Arduino @ COM5）

发送时序（真实串口）：

```
[14:40:33] 发送 '1' 到板子  (静默 15s 心跳)
[14:40:36] 识别到目标铃声  dist=0.185 rms=0.0318
[14:40:36] 发送 '1' 到板子  (识别到铃声)
[14:40:41] 发送 '1' 到板子  (铃声后随机补发)
```

识别区分度：真实铃声 dist 0.098~0.187（命中）；环境静音 0.337、叮声 0.285~0.431、白噪 0.55、正弦 1.70（均不误报）。

## 七、调参 / 注意

- **误报**：调低 `--threshold`（如 0.18）或把 `--confirm` 调到 2~3。
- **漏报**：调高 `--threshold`（如 0.28）；确认外放音量足够。
- **不想让静默心跳触发舵机**：把 `IDLE_SEND_SEC` 调大（如 3600）。
- 更换铃声：替换 `reference.wav` 即可，无需改代码。

## 八、Arduino 侧

板子程序无需改动（`ServoCmd05`：串口 9600，收到 `'1'` 执行一次动作）。
脚本连接串口时会触发板子复位（正常现象，等 2 秒即可）。
